> **PulseFit** — готовое к продакшену веб-приложение на Go для людей любого уровня подготовки.  
> Сервис формирует персональные тренировочные программы, сбалансированное меню, отслеживает прогресс на адаптивных SVG-графиках и включает диалогового ассистента с жёсткими протоколами медицинской безопасности.

---

## 📱 Адаптивный интерфейс и PWA

Интерфейс спроектирован по принципу **Mobile-First & Desktop-Responsive**:
- **На компьютерах (десктоп/ноутбук)**: полноценная верхняя панель навигации, двухколоночная раскладка дэшборда, сетка карточек упражнений и блюд в 2–3 колонки.
- **На смартфонах**: нижняя фиксированная панель табов, управление одной рукой, крупные интерактивные зоны (от 44px).
- **PWA (Progressive Web App)**: поддержка установки как нативного приложения на экран смартфона и рабочий стол ПК, автономный офлайн-кэш статики через `sw.js` и векторная иконка `icon.svg`.
- **Тёмная тема**: поддержка системной цветовой схемы + ручное переключение `🌓` с сохранением выбора в `localStorage`.

## 🎯 Ключевые возможности

### 1. Интеллектуальный онбординг и безопасность
- **Выбор и уточнение цели**: «Хочу похудеть» / «Хочу набрать вес» с безопасным темпом (спокойный ~10%, умеренный ~15%, активный ~20%).
- **Фронтенд-валидация невозможных данных**:
  - Рост: от 100 до 250 см (максимум 3 цифры, запрет букв и спецсимволов).
  - Вес: от 30 до 300 кг (максимум 5 символов).
  - Возраст: от 14 до 100 лет (максимум 3 цифры).
  - Длительность тренировки: от 15 до 120 минут.
  - Сон: от 3 до 16 часов.
- **Медицинский фильтр**: блок вопросов о травмах, хронических заболеваниях и противопоказаниях. При наличии рисков система блокирует выдачу стандартной нагрузки и направляет к профильному врачу.

### 2. Персональный тренировочный план и таймер отдыха
- Распределение тренировок и дней восстановления по дням недели (Пн–Вс).
- Подбор упражнений под имеющееся оборудование: *без инвентаря*, *домашний набор (гантели/резинки)* или *полноценный спортзал*.
- **Интерактивный таймер отдыха между подходами**: встроенный модальный секундомер с кнопками быстрых пресетов (30/45/60/90 с), добавлением времени (+15 с) и синтетическим звуковым сигналом окончания отдыха через Web Audio API (без внешних mp3 файлов).
- Кнопка **«Заменить упражнение»** — подбор функционального аналога из каталога в 1 клик.
- Подробный разбор техники: пошаговая инструкция, исходное положение, дыхание, темп, частые ошибки, подсказки по безопасности, упрощённый вариант для новичка и усложнённый вариант.
- Честный статус видео: проверенные обучающие материалы без неработающих внешних ссылок.

### 3. План питания и интерактивный водный баланс
- Распределение по приёмам пищи (завтрак, обед, ужин, перекус) с граммовками, ингредиентами и простыми рецептами.
- Варианты замены продуктов (схожие пищевые группы).
- **Отметка съеденной еды без перезагрузки экрана и без скролла вверх (AJAX / Fetch API)**.
- **Интерактивный трекер воды**: кнопки быстрого добавления (+250 мл стакан, +500 мл бутылка, -250 мл) с расчётом суточной нормы по формуле массы тела и динамическим заполнением прогресс-бара без перезагрузки страницы.
- Ориентировочный расчёт калорийности и БЖУ по формуле Миффлина — Сан Жеора.

### 4. Трекинг прогресса, ИМТ и самочувствия
- **Калькулятор Индекса Массы Тела (ИМТ)**: автоматический расчёт индекса по формуле Кетле, цветовая шкала ВОЗ (дефицит, норма, избыток, выше нормы) и определение рекомендуемого диапазона нормального веса для роста пользователя.
- Запись веса с построением адаптивного **интерактивного SVG-графика** тренда без внешних JS-библиотек.
- Ежедневный чек-ин: настроение, уровень энергии (1–5), регулярность питания, часы сна и личные заметки.
- Бережная, не осуждающая подача без давления и сравнения с другими.

### 5. База знаний и экспорт плана в PDF
- **Каталог (/catalog)**: справочник упражнений и рецептов с мгновенным живым поиском и фильтрацией по мышечным группам, типу инвентаря и пищевым категориям.
- **Экспорт в PDF (/plan/export)**: готовая чистая версия персонального плана тренировок и питания на неделю, оптимизированная для печати на формате А4 или отправки тренеру/врачу.

### 6. Диалоговый фитнес-помощник (Чат с ИИ)
- Ответы на частые вопросы (пропуск тренировки, замена продуктов, объяснение плана простыми словами).
- **Приоритет безопасности**: при упоминании острой боли, головокружения, симптомов травм или экстремального голодания ассистент даёт рекомендацию немедленно остановиться и обратиться к врачу.
- Поддержка подключения внешних моделей (`PULSEFIT_AI_KEY` / `OPENAI_API_KEY`) или работа во встроенном автономном демо-режиме.

## 🏗️ Архитектура и стек технологий

```
pulsefit/
├── .github/workflows/ci.yml    # CI/CD: автотесты, проверка гонок, сборка Docker
├── internal/
│   └── app/
│       ├── ai.go               # Движок ассистента и фильтры безопасности
│       ├── app.go              # HTTP-контроллер, AJAX API, Service Worker, PWA
│       ├── app_test.go         # Модульные и интеграционные тесты (-race)
│       ├── calc.go             # Формулы Миффлина — Сан Жеора, ИМТ, норма воды
│       ├── catalog.go          # Каталоги упражнений и рецептов
│       ├── models.go           # Доменные структуры, методы BMI, IdealWeight
│       ├── plan.go             # Алгоритм генерации персональной программы
│       └── store.go            # Репозиторий SQLite (WAL, транзакции, Foreign Keys)
├── web/
│   ├── static/
│   │   ├── app.css             # Адаптивный CSS3 (ПК + Mobile, Dark Mode, Print)
│   │   └── icon.svg            # Векторная PWA-иконка (maskable)
│   └── templates/
│       ├── catalog.html        # База знаний с живым поиском
│       ├── dashboard.html      # Главный экран с виджетами воды и питания
│       ├── layout.html         # Каркас с адаптивной навигацией и PWA
│       ├── plan_export.html    # Чистая версия плана для печати/PDF
│       ├── progress.html       # График веса, ИМТ и чек-ины
│       ├── workouts.html       # Упражнения + интерактивный модальный таймер
│       └── ...                 # Остальные страницы онбординга, чата и профиля
├── Dockerfile                  # Многоэтапная сборка легковесного образа (~20 МБ)
├── docker-compose.yml          # Развёртывание в Docker одной командой
├── Makefile                    # Команды сборки, тестирования и запуска
└── main.go                     # Точка входа, Graceful Shutdown, Security Middleware
```

- **Язык**: Go 1.24+ (без тяжелых сторонних веб-фреймворков).
- **База данных**: **SQLite** (`modernc.org/sqlite` — 100% Pure Go, CGO-Free, не требует GCC, компилируется под любую ОС и scratch/alpine).
- **Режим БД**: WAL (Write-Ahead Logging), Foreign Keys ON, автоматическое создание схемы при старте.
- **Безопасность**: Заголовки `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin`.
- **Автономность**: Все HTML-шаблоны, CSS и демонстрационные базы вшиты в бинарник через `//go:embed`. Приложение не зависит от рабочего каталога.

## 🚀 Быстрый запуск

### 1. Через Docker Compose (рекомендуется для продакшена и хостинга)

```bash
# Клонируйте репозиторий и перейдите в папку проекта
git clone https://github.com/ВАШ_ЛОГИН/pulsefit.git
cd pulsefit

# Запустите контейнер в фоновом режиме
docker compose up -d
```
Приложение откроется по адресу: 👉 **http://localhost:8099**  
Все данные сохраняются в папку `./data/store.db`.

### 2. Локально через Makefile или Go

```bash
# Запуск через Makefile
make run

# Либо напрямую через Go
go run main.go
```

### 3. Сборка статического бинарника для продакшена

```bash
make build
# Бинарник появится в bin/pulsefit
./bin/pulsefit
```

## 🧪 Тестирование и CI/CD

В проекте настроен полноценный конвейер GitHub Actions (`.github/workflows/ci.yml`), который при каждом push и PR запускает:
1. `go mod verify` — проверку целостности зависимостей;
2. `go vet ./...` — статический анализ кода;
3. `go test -v -race ./...` — модульные и интеграционные тесты с детектором состояний гонки (race detector);
4. Компиляцию бинарника под Linux;
5. Тестовую сборку Docker-образа.

Для локального запуска тестов:
```bash
make test
```

## 📋 Инструкция по загрузке на GitHub и хостингу

### Шаг 1. Инициализация репозитория и отправка на GitHub

```bash
# Инициализируйте локальный git репозиторий
git init
git branch -M main

# Добавьте все файлы
git add .
git commit -m "feat: initial commit of production-ready PulseFit app"

# Создайте новый пустой репозиторий на github.com (например, pulsefit)
# Привяжите удалённый репозиторий:
git remote add origin https://github.com/ВАШ_ЛОГИН/pulsefit.git

# Отправьте код на GitHub
git push -u origin main
```
После отправки во вкладке **Actions** на GitHub автоматически запустится CI/CD пайплайн и подтвердит успешность сборки и тестов! 🟢

### Шаг 2. Развёртывание на сервере / VPS (хостинг)

1. Подключитесь к вашему VPS по SSH:
   ```bash
   ssh user@your-server-ip
   ```
2. Установите Docker и Docker Compose (если не установлены):
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
3. Склонируйте репозиторий и запустите:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/pulsefit.git
   cd pulsefit
   docker compose up -d
   ```
4. Приложение будет работать на порту `8099`. Для привязки домена с HTTPS настройте Nginx / Caddy в качестве обратного прокси (reverse proxy):

   ```nginx
   server {
       server_name fit.yourdomain.com;

       location / {
           proxy_pass http://127.0.0.1:8099;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }
   ```
